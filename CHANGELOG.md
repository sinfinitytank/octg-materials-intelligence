# Changelog

## 1.0.0 — 2026-10-10

- Migrated all 450 supplied material records without loss or source modification; retained 36 auxiliary sources and 17 market observations.
- Added an extensible static React engineering workspace with responsive light/dark layouts and eight implemented modules.
- Added searchable/filterable/paginated/resizable material tables, source details and four-record comparison.
- Added canonical-unit well conditions, seven labelled illustrative scenarios, validation and versioned local storage/import/export.
- Added conservative mechanical/environmental screening with explicit uncertainty and preference ordering separate from eligibility.
- Added user quotation arithmetic, commercial comparability checks and historical market evidence in original units.
- Added traceable CSV/JSON exports, printable summaries, automated tests and gated GitHub Pages deployment.
- Documented legacy scoring discrepancies, engineering assumptions, architecture, data rights, contribution workflow and roadmap.
