# Feature roadmap

## Completed

- Source discovery, four-file preservation, audit and lossless 450-record migration.
- Versioned schemas, stable identities, exact raw provenance, null handling and deterministic validation.
- React/TypeScript/Vite/Tailwind foundation and modular engineering/services/reporting architecture.
- Dashboard, materials table/details, well scenarios, explainable screening, comparison, commercial quotations, reference/source registers and settings.
- CSV/JSON exports and print-friendly engineering summaries.
- Source-data corruption tests, engineering tests, React integration and production-browser workflows.
- CI and GitHub Pages workflow configuration.

## In Progress

- Final production-browser verification and live release verification (see `VALIDATION.md` for final release state).

## Planned

- Property-level evidence records, controlled review workflow, manufacturer datasheet revisions and documented product-form/condition applicability.
- Import tools for reviewed future catalogue snapshots, explicit schema migration and record-change history.
- Qualification envelope data with controlled editions and condition-specific applicability; add assertions only after validation.
- Revisioned material comparison/selection history and portable local workspace backups.
- A dedicated generated PDF module using the existing report model.
- Measured large-catalogue performance improvements when datasets exceed the current source scale.

## Deferred

- Validated CO₂ corrosion, pitting/SCC, mechanical collapse/burst/combined-load and casing/tubing design models.
- Life-cycle costs, corrosion mitigation, inspection, replacement and production-loss economics.
- AI-assisted discovery or PDF extraction; every proposed fact would still need source and applicability review.
- Authentication, shared backend, paid APIs and multi-user collaboration until an approved workflow requires them.

Deferred models require an engineering validation basis and are absent from production navigation.
